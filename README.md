# ARTIS Incident Report Form

A React-based incident reporting form for near miss, incident, and accident reporting.

## Features

- Multi-page form with progress tracking
- Form validation
- Responsive design
- Form data submission
- Success/error handling

## Installation

1. Clone the repository
2. Run `npm install`
3. Run `npm start`

## Form Structure

- Page 1: Incident Details
- Page 2: Injured Person Details
- Page 3: Incident Matrix Type
- Page 4: Further Details
- Page 5: Incident Investigation
- Page 6: Follow Up & Close Out
- Page 7: Person in Control
- Page 8: HSE Department
- Page 9: Final Approval
